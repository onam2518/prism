  지정된 사람만 판정 · **생성자·관리자도 예외 없음**"을 강제한다. 그런데 07-22 커밋
  `36a9d3c` 이 "생성자가 타인 배정분을 못 본다"는 신고를 고치면서 **열람 예외와 함께
  판정 잠금까지** 풀었다. 결과: 버튼도 판정 버튼도 열려 있는데 누르면 서버가 거절하는
  막다른 길. `20-ingest-policy.html` 주석에는 "생성자·관리자 포함"이라 적혀 있어
  원래 의도도 잠금이었다.
- **수정**: 열람 예외와 판정 규칙을 분리했다.

  | 함수 | 역할 | 관리자 예외 |
  |---|---|---|
  | `assignBlocked`(신규·공용) | 판정 가능 여부 단일 원천 | 없음(서버와 동일) |

  | `detailAssignBlocked` | 상세 판정 버튼 잠금 | 공용 규칙에 위임 |

- 버튼을 그냥 없애면 이유를 알 수 없어, 자리에 `🔒 담당자 검수`를 두고 클릭하면 열람은
  되게 했다. 잠금 안내 문구가 "콘텐츠 관리에서"를 가리키던 것도 실제 배정 위치(담당 열의

- 회귀 테스트 4건. 화면 규칙과 서버 게이트가 다시 어긋나면 잡힌다.

- 덤: 자동 다음 이동(`detailNextTodo`)이 타인 배정분(판정 불가)에 멈추던 것도 건너뛰게.

## 모델 큐 전건 이상 출력 = 라우터 잔액 소진 (진단)

- **신고**: "방금 돌린 콘텐츠 모델 큐가 전부 값이 이상하게 출력된다."
- **확인**: 최근 배치 200건이 카테고리·엔티티·요약·등급 **전부 빈 값**. 실패 원장
  (`fail_rollup`)에 07-28 자 `http_402` **800건**(200건 × 콜 4종). 라우터에 최소 호출을
  직접 넣어 현재도 같은 응답임을 확인.

  ```
  HTTP 402  {"code":"insufficient_balance",
             "message":"Insufficient balance for this request."}
  ```

- 운영 텍스트 모델은 **Timely 라우터**(`PRISM_TIMELY_KEY` · `router.stg.timelyai.io`)를 탄다.
  코드 결함이 아니라 계정 잔액 문제이고, 과금은 $0 이라 돈이 나간 건 아니다.
- **다만 실패해도 행은 저장된다**: `runops` 가 산출이 비어도 `store_save` 를 태워
  200건이 YELLOW 로 검수 목록에 올라왔다. 폴백 체인(`fallback_models`)은 같은 라우터
  키를 쓰니 함께 402.
- **복구 걸림돌**: 「메타 생성 실패 콘텐츠」의 건별 재실행 목록은 상한이 100건
  (`dashops._RECENT_FAIL_CAP`)이라 실패 200건 중 절반만 등재됐다. 일괄 재실행 범위도
  '미실행만'(해당 없음) / '전체'(600건 · 과금 큼) 둘뿐이라 **빈 산출만 골라내는 범위가 없다**.

## 모델 선택 드롭다운 · 9곳 통일 (#334)

참고 UI(Timely 고객센터 모델 선택)를 받아 같은 결로 만들었다.

- 모델 고르는 자리가 원본 id(`claude-opus-4-8`)를 그대로 뿌리는 네이티브 `<select>` 라
  무엇을 고르는지도 얼마나 비싼지도 알 수 없었다. **9곳 전부** 같은 드롭다운으로 통일
  (사용 모델 · 검수 대상 모델 필터 · 전용 프롬프트 · 평가 기준 · A/B 비교 2곳 · 사전 ·
  프롬프트 스튜디오 2곳).
- `prism/modelmeta.py`(신규): id → 읽는 이름(`Claude Opus 4.8`) · 제공자 계열 · 비용 등급.
- **등급은 실제 누적 비용 원장(cost_rollup)에서 계산**하고 건당 평균도 같이 보여준다.
  등급을 못 붙인 모델도 숫자는 남아 판단 근거가 된다.
- **함정**: 실데이터로 돌려 보니 Opus 에 고비용이 안 붙었다. 오늘 402로 실패한 600건이
  과금 0으로 평균을 끌어내린 탓.

  | | 실행 | 과금 | 건당 평균 |
  |---|---|---|---|
  | 07-15~22 정상 | 627 | $4.23 | **$0.0067** |
  | 07-28 전건 402 실패 | 600 | $0.00 | $0 |
  | 그냥 합치면 | 1227 | $4.23 | $0.0034 ← 고비용인데 무표기 |

  → 과금 0 인 묶음은 표본에서 제외. 표본 20건 미만도 무표기(평균이 튄다).
- **마크업 중복 방지**: 조각에는 `<x-modelpick …>` 한 줄만 쓰고 `page.py` 합성 중에
  드롭다운 마크업으로 펼친다. 같은 드롭다운을 9벌 복사하면 한 곳만 고쳐지는 사고가 난다.
- **메뉴가 잘리던 문제**: 패널이 `overflow:hidden` 인 데다 `:hover` 에 `transform` 이
  걸려 있어(카드 뜨는 효과) `position:fixed` 로도 패널 안에 갇힌다. `x-teleport` 로
  body 에 빼내고 열 때 화면 좌표를 재서 붙였다. `x-transition` 은 텔레포트된 요소에서
  떠날 때 전환이 끝나지 않아(Alpine 3.14) 빼고 `x-show` 만 쓴다.
- 제공자 배지는 외부 로고 없이 **계열 머리글자 + 계열색**(자체완결 · CSP 안전).
- 라우터 모델 목록이 서버(`KNOWN_ROUTER_MODELS`)와 화면(`modelCatalog`) 두 곳에 있어
  동기화 테스트를 뒀는데, 작성 즉시 실제 누락(`openai/gpt-5-mini`)을 잡았다.
