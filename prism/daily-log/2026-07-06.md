## 오늘 확정된 운영 지식

- **운영 루프(안전)**: 배치 추가 → 한 모델 실행(vN) → 퀘스트 생성 → 검수 완료 → 학습 반영(vN+1) → 다음 배치. 검수 사이클 중 재실행 = 합의 오염(결과 행이 최신 초안으로 upsert 되므로) → v0.5.17 가드로 물리 차단.
- **정답셋은 모델 무관 단일 진리**(콘텐츠 단위). 모델별 분기는 초안(drafts hash×model×version)·프롬프트(계열 래퍼+LEARNED_BY_MODEL)·평가 결과. 모델 비교는 평가 탭(읽기 전용)에서.
- **⚡ 즉시 반영은 목표(learn_next_at)를 소진하지 않음** — 소진은 스케줄 도달 시에만.
- supabase 데이터 정리 완료(콘텐츠 190·초안 370 삭제 · 팀/검수자/가이드 링크 보존). QA 임시 계정·팀도 전부 정리.
