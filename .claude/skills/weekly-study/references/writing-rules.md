# 문장 규칙

AI 가 쓴 티가 나는 한국어 패턴을 걷어내고, 대신 구체성을 넣는다.
분류 체계 출처: https://github.com/epoko77-ai/im-not-ai (MIT)

원칙은 셋이다. **뜻은 그대로 두고, 검출된 구간만 고치고, 슬라이드라는 장르를 지킨다.**
수치·고유명사·인용문은 글자 단위로 보존한다.

## 반드시 잡는 것

### 연결어미 뒤 쉼표

`-고, ` `-며, ` `-지만, ` `-면서, ` → 쉼표를 지우거나 문장을 나눈다.
AI 19.8% 대 사람 4.1%. 단일 지표로 가장 강하다.

> 열쇠 하나하나는 잘 만들어졌지만, 꾸러미를 관리하는 일이 감당이 안 됩니다.
> → 열쇠 하나하나는 잘 만들어졌습니다. 감당이 안 되기 시작한 쪽은 꾸러미를 관리하는 일이었습니다.

### "A가 아니라 B" 부정 대구

한 문서에 3회를 넘기지 않는다. AI 5.8 대 사람 0.6.

> 도구를 대신하는 것이 아니라, 꽂는 자리를 표준으로 만든 것입니다.
> → 도구를 대신하지 않습니다. 도구를 꽂는 자리를 표준으로 만들었습니다.

### 상투구

`결론적으로` `요약하면` `정리하면` `~라고 할 수 있다` `시사하는 바가 크다`
`매우 중요하다` `주목할 만하다` `다음과 같은` `크게 세 가지로 나눌 수 있다`
→ 삭제하고 바로 본론.

### 과장 어휘

`혁신적` `획기적` `압도적` `막강한` `폭발적` → 수치나 사실로 바꾼다.

> 압도적으로 많이 쓰는 것은 → 실무에서 가장 많이 쓰는 것은

### 정도부사

`매우` `정말` `극히` `굉장히` → 대부분 삭제.

### 문두 접속사

`또한` `따라서` `즉` `나아가` `아울러` `게다가` → 70% 이상 삭제.

| 패턴 | 처방 |
| --- | --- |
| `~에 대해` `~에 있어서` | 목적격 조사로 직결 |
| `~를 통해` 남발 | `~로` `~해서` 로 분산 |
| `가지고 있다` | 형용사형으로 · "권한을 가지고 있다" → "권한이 있다" |
| `~에 의해` 피동 | 행위자를 주어로 · "AI 에 의해 생성" → "AI 가 만든" |

| 대시(—) | 쓰지 않는다. 가운뎃점(·)이나 문장 분할로 |

## 리듬

- 문장 길이를 섞는다. 단문(10~15자) 한둘에 장문(80자+) 하나를 문단마다 넣는다.
- 같은 종결어미를 4문장 이상 연달아 쓰지 않는다.
- 슬라이드 전체는 합쇼체(`~습니다`)로 통일한다. 표 안은 `~다`체를 써도 된다.
- 헤드라인은 서술형 한 문장으로. 명사구나 의문형으로 끝내면 나머지 슬라이드와 톤이 어긋난다.

> 자주 하는 오해 네 가지. → 오해 네 가지를 짚고 갑니다.
> API 와 어디서 갈라지는가. → API 와 갈라지는 지점은 여섯 곳입니다.

## 용어

**표준 개념어를 임의로 번역하지 않는다.** 뜻이 겹치는 새말을 지어내면 개념이 충돌한다.
실제로 MCP 덱에서 Prompts 를 "서식"이라 부르는 바람에, tool description 을 가리키는
"설명문"과 개념이 뒤엉킨 적이 있다.

| 이렇게 쓴다 | 이렇게 쓰지 않는다 |
| --- | --- |
| 프롬프트 · Prompts | 서식 |
| 리소스 · Resources | 자료 |
| 도구 설명 · description | 설명문 |
| 전송 방식 · transport | 붙는 방식 |
| 무상태 · stateless | 상태 없는 방식 |
| 핸드셰이크 · handshake | 인사 절차 |
| 로드 밸런서 | 부하 분산기 |

**처음 나오는 자리에 범례를 단다.** `우리말 · 원문 표기 · 한 줄 뜻`.
원문 표기를 남기는 이유는 검색 때문이다. 공식 문서는 대개 영어다.

## 구체성

두루뭉술한 문장은 사실로 바꾼다. 슬라이드 한 장에 최소 하나는 검증 가능한 사실이 있어야 한다.

| 두루뭉술 | 구체 |
| --- | --- |
| 인증 방식이 서비스마다 다릅니다 | 슬랙은 봇 토큰, 구글은 OAuth 동의, 사내 DB 는 계정과 접속 정보 |
| 세 가지 약속입니다 | tools/list · tools/call · 결과 형식을 JSON-RPC 2.0 위에서 |
| 느리고 비쌉니다 | API 는 수 밀리초, 모델 판단은 수백 밀리초에서 수 초 |
| 취약점이 발견됐습니다 | 2025년 7월 10일 중단 · 읽기 전용 보호를 우회하는 SQL 인젝션 |
| 토큰을 많이 씁니다 | 15만 → 2천 토큰 · 2시간 회의록이 두 번 지나가며 5만 토큰 |

수치에는 기준 시점과 출처를 붙이고, 부록 표에 같은 번호로 연결한다.
실험값을 인용할 때는 재현한 값이 아니라는 점을 밝힌다.
