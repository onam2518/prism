# prism-review-week · 주간검수생성

주차별로 받은 후보 CSV에서 **누적 검수가 부족한 인텐트부터** 골라 운영 프리즘(DNM 팀)에 등록하고 배정한다.
주차 계획은 운영 `reports`(kind=`review_week_plan`)에 남는다. 다음 주 실행은 이 계획을 읽어서
**채우지 못한 인텐트에 가중치**를 준다. 연속으로 못 채운 주마다 가중치가 +50%씩 붙는다.

스크립트: `.claude/skills/prism-review-week/review_week.py` (state → select → apply)

## 입력
- **후보 CSV:** 열은 `content_unique_key, displayServiceName, title, grade, reasons, evidence, summary, entities, intent, content_category, url, tokens, cost_krw`다. 주제는 `displayServiceName`(뉴스·연예·스포츠)으로 나누므로 파일이 섞여 와도 된다.
- **본문:** CSV에 본문이 없어서 `url`(v.daum.net)에서 본문과 이미지를 직접 받는다.
- **담당 조합:** 스크립트 상단의 `ROSTER`가 정한다. 바뀌면 그 상수만 고친다.
  - 뉴스 = 메리메리 + 라이언
  - 연예 = 비니 + 김덕호 기초검수(켄드릭)
  - 스포츠 = 애쉬 + 김덕호 기초검수(켄드릭)

## 순서
작업 디렉토리는 세션 scratchpad 아래 새 폴더를 쓴다. 받은 CSV도 거기로 복사한 뒤 다룬다. 운영 접근(`fly ssh`)과 원문 수집은 네트워크를 쓰므로 샌드박스 해제가 필요하다.

1. **상태 수집** (읽기 전용)
   `python3 -I review_week.py state --dir $W`
   - 받는 것: 누적 검수 완료와 배정 대기, 기존 URL, 이번 주 이미 등록한 배치, 지난 주 계획
   - 첫 주면 "지난 계획: 없음"이 나온다.
2. **선정**
   `python3 -I review_week.py select --dir $W --csv <파일들>`
   - 출력은 주제별 후보·선정·신규·유지·제외 건수다.
   - 인텐트별로 목표·확보·선정·부족을 보여 주고, 몇 주째 연속 부족인지도 함께 표시한다.
   - `!` 줄은 메타(카테고리·인텐트·엔티티)가 빈 행이다. 선정에서 빠지므로 사용자에게 그대로 알린다. 추출 누락으로 볼 수 있다.
3. **사용자 확인:** 선정 요약과 부족한 인텐트 표를 보여 준다. 반영 전에 진행 여부를 묻는다. 사용자가 "반영해"라고 이미 말했으면 생략한다.
4. **dry-run → 반영**
   - 먼저 `apply --dir $W`(dry-run)로 삭제·신규·이미 있음 건수를 확인한다.
   - 그다음 `apply --dir $W --go`로 실제 반영한다.
5. **보고**
   - 주제별 반영 건수와 인당 배정량을 알린다.
   - 남은 부족분은 "다음 샘플 요청 목록"으로 정리한다. 부족분의 약 2배를 요청하고, 같은 사건·같은 아티스트가 아닌 기사로 달라고 한다.

## 같은 주에 샘플을 추가로 받으면 (재편)
같은 `--week`(기본값: 이번 주)로 1~4를 다시 돌린다.
- **후보:** 이번 주 이미 등록한 배치도 후보에 다시 들어간다. 새 샘플과 합쳐 처음부터 다시 고른다.
- **빠지는 건:** 판정이 없는 것만 콘텐츠·배정을 함께 삭제한다. 삭제 직전에 운영에서 판정 여부를 다시 확인한다.
- **판정이 들어간 건:** 항상 남긴다.

## 선정 규칙 (review_week.py)
- **목표:** 그 주 후보에서 해당 인텐트가 차지하는 비중으로 정한다. 10% 이상이면 30건, 3% 이상이면 20건, 그 아래는 10건이다.
- **대상 인텐트:** 비중 1% 이상인 것, 주제 고유 인텐트(`OWN`), 지난 주에 못 채운 인텐트다.
- **확보:** 검수 완료 건과 이전 주차의 배정 대기 건이다. 인텐트는 2·3순위까지 모두 센다.
- **점수:** 인텐트별로 '가중치 × 남은 부족분 ÷ 목표'를 더한다. 탐욕적으로 고르고, 1차 카테고리 상한은 20건이다.
- **고정 포함:** 판정이 들어간 건과 유통불가(R) 판정 건이다.
- **제외:**
  - 중복 제목
  - 같은 사건 기사(엔티티 겹침 50% 이상)
  - 본문이 없는 영상 기사
  - 이미 운영에 있는 URL
  - 메타가 빈 행
  - TV 출처 인텐트 4종
  - 뉴스 중 스포츠·연예 카테고리 기사, 스포츠 중 게임 카테고리 기사
- **엔티티:** "외 N"으로 잘린 꼬리는 지우고 등록한다. 엔티티가 일부만 들어가므로 보고할 때 알린다.

## 함정
- **로컬 키 파일:** `~/.prism_supabase_url`은 옛 프로젝트라 DNS 조회가 실패한다. 운영 작업은 반드시 `fly ssh console -a prism-item`(스크립트가 처리)으로 한다.
- **머신 자동 정지:** 운영 머신은 자동으로 정지된다. 스크립트가 먼저 사이트를 호출해서 깨운다. "no started VMs"가 나오면 잠시 뒤 다시 돌린다.
- **CSV 위치:** 바탕화면 정리 자동화가 `~/Documents` 의 CSV를 `프로젝트/Prism/테스트 파일/`로 옮긴다. 경로가 사라졌으면 `mdfind -name`으로 찾는다.
- **표시명:** 담당자의 사내 ID와 프리즘 표시명은 다르다. 매핑은 `ROSTER` 주석을 본다. 표시명이 바뀌면 select 단계에서 "팀 멤버 없음"으로 멈춘다.
