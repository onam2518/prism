# Prism 로고 가이드

디자인 시스템(Anchor Blue · 무채색 캔버스 · 둥근 친근함 · 다음프렌즈 캐릭터)과 한 몸인 **귀여운 카툰형 로고**.

## 컨셉

**빛을 받아 메타로 분산하는 프리즘.** Blue 삼각 프리즘이 들어온 빛을 받아 **스펙트럼 색**으로 흩뿌린다 = 이미지 → 메타데이터. 웃는 얼굴로 "딱딱하지 않게"(서비스 톤과 일치).

```
  (빛) ─▶  ◢◣ 웃는 프리즘  ─▶ ● violet
                              ● green
                              ● orange  (분산된 메타)
```

## 구성

| 요소 | 설명 | 파일 |
|---|---|---|
| **마크(심볼)** | 웃는 Blue 프리즘 + 입력 빛 + 분산 점 3 | `assets/logo/prism-mark.svg` |
| **풀 로고** | 마크 + 워드마크 "Prism" | `assets/logo/prism-logo.svg` |

- **워드마크**: Pretendard · 600 · letter-spacing −0.6 · 잉크 `#000000`.

## 색

| 부분 | 색 |
|---|---|
| 프리즘 몸통 | Anchor Blue `#1e84ff` (Blue.500) |
| 분산 점 | violet `#a05cff` · green `#18ba45` · orange `#ff9429` (Anchor 스펙트럼) |
| 얼굴(눈·입) | 잉크 `#000000` / 흰자 `#ffffff` |
| 입력 빛 | muted `#8e949b` (Gray.400) |

## 사용 규칙

- **마크 단독**: 파비콘·앱 아이콘·사이드바 로고·작은 자리. 최소 **20px**.
- **풀 로고**: 가로 헤더·문서·랜딩. 최소 폭 **96px**.
- **클리어스페이스**: 마크 높이의 **0.5배** 여백 확보.
- **다크 배경**: 프리즘은 Blue 유지, 워드마크는 off-white `#ffffff`로. 분산 점·얼굴 그대로.

## Don't

- 비율 왜곡·회전·기울임 금지
- 프리즘을 Blue 외 색으로 채색 금지(분산 점만 컬러)
- 외부 그림자·그라데이션·네온 추가 금지(무채색 캔버스 유지)
- 얼굴 제거 금지(친근함이 정체성) · 분산 점 색/개수 변경 금지
- 순백/검정 배경 위 사용 금지 · 캔버스(`#f4f5f7`)나 surface 위에

---

> 로고는 브랜드 토큰을 따른다. 색이 바뀌면 여기와 `assets/logo/*.svg`만 고친다. 캐릭터(다음프렌즈)와 함께 "친근하지만 절제된" 톤을 지킨다.
