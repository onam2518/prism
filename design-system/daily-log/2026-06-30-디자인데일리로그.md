> 프로젝트 데일리로그(`prism/daily-log/`)와 분리된 **디자인 전용 로그**.

**Anchor Design System(axz)을 디자인 원칙(Source of truth)으로 전면 채택.** 그동안의 Perplexity 정렬(따뜻한 페이퍼 + Peacock teal · FK Grotesk)을 폐기하고, 사내 표준인 Anchor(무채색 캔버스 + Blue/Red + 도메인 카테고리색 · Pretendard · Light/Dark)로 **팔레트·타이포·지오메트리·그림자·Button 계약**까지 전면 이행(v0.3.0). 사용자 지시: "디자인 이 요소들도 반영해줘. 원칙이야."

## 한 일

### 1. Anchor 원본 반입 (Source of truth)
- `DESIGN.md`·`Button.md`·`tokens.json` → **`design-system/anchor/`** 에 거버닝 레퍼런스로 박제.
- 본 패키지의 `tokens/tokens.json`·`src/theme.css`는 Anchor semantic 토큰을 `--ds-*` 변수로 박제한 것임을 명문화. 원칙: **Semantic 토큰만 · Primitive 직접 참조 금지 · Light/Dark 분기 금지**.

### 2. 토큰 전면 재도출 (teal → Anchor)
- **컬러**: primary `#20808d`(teal) → `#1e84ff`(atomic.Blue.500). accent = `#ff4e33`(Red.500). 무채색 캔버스(`background.base #f4f5f7` / `surface.base #ffffff`), 텍스트는 알파 기반(`text.secondary rgba(0,0,0,.88)` 등).
- **카테고리 식별색** 신설: 뉴스(Blue)·쇼핑(Red)·스포츠(Indigo)·연예(Violet)·카페(Coral)·관심사(Orange)·커뮤니티(Lavender) — 각 `--ds-cat-*` / `-subtle` / `-text`.
- **타이포**: Pretendard 단일 패밀리. 사이즈 스케일 11단(12·14·15·16·17·18·20·22·24·26·40), 줄간격 1.2/1.32/1.4/1.52, 굵기 enum 400·600·700.
- **지오메트리**: Radius 4·8·12·16·24·100(pill). **그림자 3단**(low·medium·high, 다크 알파 2배). Anchor 원칙대로 "깊이는 surface 대비가 1차, shadow는 보조".
- 적용 파일: `theme.css`·`tokens.ts`·`tailwind.preset.cjs`·`tokens/tokens.json`. **`--ds-*` 변수 API는 그대로 유지**(값만 swap) → 기존 50+ 컴포넌트 무수정 호환. 구 이름(`shadow-standard`·`weight-semibold` 등)은 별칭으로 보존.

### 3. Button — Anchor Button.md 계약 반영
- 구 `variant=primary|secondary|ghost|pill` → **Variant(Solid·Outline) × Color(Primary·Secondary·Subtlest·Neutral·Inverse·Ghost·Danger) × Size(Sm~3Xl) × Shape(Square R8·Rounded R100) × State** 풀 계약으로 재구성.
- **HoverLayer**(공통 오버레이 `state.hover`) · **FocusRing**(Blue 2px) · **Loading**(라벨·아이콘 숨김 + 스피너, 폭 고정) · **Disabled**(`interaction.disabled`/`text.disabled`) 구현.
- Solid/Outline 색 매트릭스를 §3-1·§3-2 그대로 토큰 바인딩. 사이즈 스케일(높이 32~56, 타입/패딩/gap) §3-3 반영.
- 구 API는 **back-compat 시ON**으로 무중단 매핑(primary→Solid/Primary, pill→Solid/Secondary/Rounded 등).

### 4. 앱(serve.py) 재벤더링 + 잔여 하드코드 정리
- `design-system/src/{theme,components}.css` → `prism/vendor/ds-{theme,components}.css` 재벤더.
- 앱 Tailwind 토큰(`violet`=역사적 유틸명) 값을 Anchor Blue로 통일. 앱 레벨 별칭 블록(`--ds-violet*`·`--ds-surface2`·`--ds-solar`) 추가 → `var(--ds-violet,#20808d)` 폴백 의존 제거.
- 잔여 하드코드 일괄 치환: teal `rgba(32,128,141,…)`→Blue, 잉크 그림자 `rgba(9,23,23,…)`→`rgba(0,0,0,…)`, 따뜻한 뉴트럴 폴백(#fbfaf4·#fcfcf9·#e4e4dc·#e5f2f2 등)→Anchor 뉴트럴. 고정 위젯 테두리 teal 틴트→Blue 틴트.
