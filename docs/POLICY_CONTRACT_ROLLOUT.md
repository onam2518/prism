# 공통 메타 저장·평가 전환

새 추출 프롬프트는 `imeta@v21`이다. 엔티티는 `{name,type}`(PS·OG·LC·AF·EV·TM·null), 카테고리는 `{tier1,tier2}` 객체를 사용한다. 기존 문자열 이력은 읽기·표시 호환을 유지하며 새 정책으로 재확정된 것으로 간주하지 않는다. 검수 화면의 엔티티 확신도는 참고 표시이며 발행 필터가 아니다.

- 네 호출은 독립 실행한다. `meta_status`는 success/no_value/insufficient_input/call_failed/invalid_output/configuration_error를 구분한다. 빈 텍스트는 호출하지 않는다.
- `input_revision`은 실제 호출 입력과 보조 정보의 제공 여부를 식별한다. `run_manifest`는 호출별 모델·프롬프트 지문·시도 수를 보존한다. 이미지 정보 없음과 0장을 구분한다.
- 검수 수정은 `manual_fields`에 근거를 남긴다. 자동 저장은 수동값을 보존하고 다른 입력 revision에서는 pending과 `manual_review_required`로 재검수를 요구한다.
- `source_fields`는 원천값의 미제공/null/빈 문자열을 구분한다. source_key_status는 키 구조의 관찰값이며 DNM 대상 여부를 뜻하지 않는다.
- 공통 메타 정답은 품질등급 없이 등록할 수 있다. 품질 지표에는 별도 `grade_n`을 사용하며 미판정을 G로 바꾸지 않는다. 재확정 대기 인텐트와 관리 표식은 SFT 정답에 포함하지 않는다.
- 정답 메타(등급·인텐트·분류·요약·엔티티)는 값이 있던 축이 쓰기에서 빠지거나 빈 값이 되어도 DB 트리거 `prism_golden_meta_keep`이 이전 값을 유지한다. 삭제 후 재삽입은 최근 이력에서 되살린다. 의도적으로 비울 때만 같은 트랜잭션에서 `set local prism.golden_allow_meta_clear = 'on'`을 쓴다. 정답셋 업로드는 기본 병합이며 전체 교체는 `replace=1`을 명시한다.
- 정답 수정·교체 이전 값은 `golden_history`에 보존한다. 평가 재개는 정답·프롬프트·설정 지문이 일치할 때만 허용한다. 지문이 없는 과거 런은 새로 시작한다.
- 토픽의 삭제·운영 보류·명시적 대상 철회는 개별 포함으로 해제할 수 없다. 날짜는 KST 달력일 경계를 사용하며 발행일 부재를 적재일로 대체하지 않는다.
- 조건식 `condition_expr`는 all/any/not 트리와 `{field,op,values}` 잎으로 보존한다. field는 entities/intent/content_category/source, op는 in/eq다. 미판정은 부정해도 미판정이다. 같은 축의 flat 복수값은 OR다.
- 비중 조절(더/덜)은 필터로 변환하지 않고 확인 대상으로 반환한다. 기간·원천 조건이 다른 토픽은 자동 병합하지 않는다. 병합 결과는 초안이며 원본 ID를 별칭으로 보존한다.

## 배포 순서

1. 전체 테스트와 migration 내용을 검증한다.
2. `supabase/migrations/20260929095333_preserve_content_source_fields.sql`을 운영 프로젝트에 적용한다. source_fields, 수동값 보호 트리거, 정답 이력 표를 먼저 설치한다. 기존 원문·정답을 자동 재작성하지 않는다.
3. 앱을 배포하고 source_fields 왕복, 수동값 보호, 정답 이력, DB 권한을 확인한다.
4. 기존 정답의 재확정은 운영 검수자가 수행한다. 원래 없던 원천키와 엔티티 타입을 추정해 과거 행에 채우지 않는다.

## DNM 운영 전환에 남은 조건

이 보완을 전체 DNM 발행 전환 완료로 해석하면 안 된다. 승인된 인입 경로 등록표와 적용 대상이 확인되기 전에는 자동으로 eligible을 부여하지 않는다. 일반 실험 입력에는 운영 키를 강제하지 않는다.

등록표 기반 scope 철회·복귀, 원천키를 기준으로 한 불변 작업·발행 revision과 지연 응답 선택, 전체 실행 중 설정 고정, 토픽 미리보기 승인 버전·되돌리기 충돌 검사, 외부 참조를 포함한 병합 미리보기는 별도 전환 조건이다. 새 상태나 입력 지문만으로 이 조건들이 충족된 것으로 보지 않는다.

## 입력 예제

`data/common-meta.template.jsonl`은 품질등급 없는 공통 메타 정답의 형식 예제다. 실제 원문과 검수된 정답으로 교체해서 사용한다. input_revision은 실제 입력으로 계산하며, 확인하지 않은 정책 버전이나 원천키를 예제 값으로 채우지 않는다.
