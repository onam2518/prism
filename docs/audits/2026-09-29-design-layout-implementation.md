# 공통 배치 컴포넌트 정비 결과

2026-09-29 · [진단 및 견적](2026-09-29-design-layout-audit.md)에 따른 구현 결과.

## 적용

공통 CSS 담당, 평가·비교 담당, 운영 화면 담당으로 파일 소유권을 나눠 구현했다. 최신 main `ab8698f`에서 별도 배포 작업 트리를 만들어 이번 변경만 통합했다. 평가·사전·설정의 충돌은 최신 기능을 보존하며 해결했다. 원래 작업 트리의 미커밋 기능 개발은 유지했다.

- 패널·표: 본문 내부의 중복16px 인셋 제거. 패널 직속 표·필터는 제목과 같은20px 외곽. 첫/마지막 셀 좌우14px 통일.
- 컨트롤: `control-row`36px / compact32px. 버튼·입력·선택·필터칩·복합 선택기의 외곽 높이를 통일. textarea는 제외.
- 통계: 최소 칸140px, 기본 최대4열 및3/5/6열 변형. 좁아지면 자동 줄바꿈.
- 2열 영역: 공통 `layout-grid--two`로 교체,1100px 이하 한 열.
- 헤더: 제목·설명·조작 그룹 줄바꿈. 긴 제목을 숨겨 잘라내지 않도록 조정.
- 모델 비교: 항목 열180px 고정, 모델 열 최소200px·동일 너비, 항목 열 sticky. 표 안에서 가로 스크롤.
- 팀 권한 표: 공통 compact 표 적용.
- 비교 진척도 창: 기존 PR #534의 반응형 배치만 재사용. API 동작은 유지.
- 상태 배지: success/error/warning/neutral 한 줄 유지. 장문 일반 태그는 줄바꿈 허용.
- 평가 빈 상태: `x-show`만으로 보호되지 않던 결과 표시2개의 null 접근 오류 수정.

화면별 클래스 교체는 기존 UI 조각17개에 적용했다. 공통 CSS가 적용되는 다른 화면도 같은 규격을 상속한다. 모든 화면을 새로 작성한 것은 아니다.

실제 페이지 검사는 앱 마크업과 스크립트에 데모·합성 데이터를 넣은 로컬 Chromium 환경에서 수행했다. 실제 운영 API, 계정별 권한 전체 조합, 다른 브라우저 엔진을 검증한 결과는 아니다. 비교창은 외부 요청을 차단한 fixture로 검증했다.

## 배포 통합 검증

최신 main 통합본의 전체 unittest 2,197개 실행 성공(13개 skip), 공통 컴포넌트18개 화면 크기·테마 조합 통과. 기존 인텐트68·평가 단계 진척·중지 처리·품질 설정 설명을 보존했다. 브랜치 PR 병합 후 기존 Fly Deploy 워크플로를 사용한다.
