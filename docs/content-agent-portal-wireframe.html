콘텐츠 에이전트 · 포털 홈 재정합

실제 포털 홈(Daum 참조)의 콘텐츠 모듈이 곧 위젯이다. 콘텐츠 에이전트는 이 홈 위에 얹혀 사용자가 위젯을 고르고·크기·순서·삭제하고, 왜 떴는지 + 피드백까지 하게 만든다. 검색·로그인·날씨 같은 시스템 영역은 편집 대상이 아니다.

상주 에이전트

홈을 안 바꾸고도 오른쪽 아래에 늘 떠 있다. 누르면 위젯을 말로 바꾸거나 편집 모드로.

3

추천 모듈에 왜?+피드백

"이 시각 추천뉴스"의 ⓘ를 전면화. 왜 떴는지 한 줄 + 좋아요/관심없음으로 바로 학습.

4

시스템은 편집 불가

검색·로그인·날씨는 포털 기본이라 위젯 편집 대상에서 제외. 빗금으로 구분.

PC · 편집 모드 + 위젯 갤러리

에이전트를 열면 위젯이 편집 상태(흔들림)로. 끌어서 순서, 크기 바꾸고, 지우고, 갤러리에서 실제 모듈을 골라 추가.

편집 = 홈 위젯 다루듯

흔들리는 위젯을 끌어서 순서, 크기(작게·보통·크게), 지우기. 익숙한 홈 화면 편집 그대로.

5

갤러리 = 실제 모듈

추상 "재료"가 아니라 이 홈의 실제 모듈(나를 위한·인기·우리지역·스포츠·머니·심층탐사…)을 골라 얹는다.

머니 위젯을 맨 위로 옮기고 크게 키웠어요. 되돌릴까요?

시트로 고르거나, 매니저에게 말로. 둘 다 같은 위젯을 다룬다. "우리지역을 경기로", "인기 위젯 빼줘"처럼.

1

얹히는 레이어

기존 포털 홈을 갈아엎지 않는다. 그 위에 에이전트 · 편집 · 왜/피드백만 얹는다.

2

모듈 = 위젯

뉴스·추천·지역·라이브·쇼핑 모듈이 곧 편집 가능한 위젯. 크기·순서·삭제는 홈 위젯 다루듯.

3

왜?+피드백이 킥

"이 시각 추천뉴스" ⓘ를 전면화. 왜 떴는지 + 좋아요/관심없음으로 그 자리에서 학습.

6

시트 = 대화, 한 대상

갤러리 시트로 고르든 매니저에게 말하든 결과는 같다. 손과 말, 둘 다 열어둔다.

포털 홈 재정합 와이어 · 실제 모듈을 위젯으로. 브랜딩·픽셀이 아니라 구조·위치 확인용.
