## 실제 모델 호출

합성 콘텐츠 2개를 개선용 1개·평가용 1개로 나누고, 격리한 임시 DB에서 Solar Pro 4로 튜닝 1회 실행. 기준 평가·개선용 재실행·개선안 생성·후보 평가 완료. 정답 변경과 자동 채택 없음, 평가용 콘텐츠가 개선 프롬프트에 포함되지 않음을 확인.

완전 일치 결과는 기준 0/1, 후보 0/1. 이번 검사는 실제 호출 경로 확인이며 품질 향상 근거는 아님. 단가 정보가 없는 모델의 비용은 미집계로 유지.

앞선 연결 확인에서는 로컬 Timely 키의 인증 실패, Solar Pro 3의 개선안 형식 오류로 중단. 잘못된 응답은 후보로 저장되지 않았으며 정답·채택 상태 보존. 프롬프트 작성법을 추출 규칙으로 옮기지 않도록 개선 지시를 보완한 뒤 Solar Pro 4로 재실행.

## 문서·화면 검수와 남은 제한

- `slop-check` 로컬 린터와 직접 검토 적용. 가이드의 단계 화살표는 순서 안내로 유지, 기존 절의 UI 명칭과 인용은 보존
- 최신 가이드 전체 4화면 렌더링 확인, 가로 넘침 없음. 검수 완료·튜닝 결과 화면 캡처 확인
- Astryx CLI는 이 저장소에서 `@astryxdesign/core` 패키지를 찾지 못해 사용 불가. 기존 Alpine 화면과 네이티브 입력·fieldset을 사용하며 새 실행 의존성 없음
- 실행기 1개를 전제로 한 구현. 서버 재시작 시 진행 중 튜닝은 중단으로 표시하며 자동 재개하지 않음
- 선택한 평가용 정답을 반복 비교하므로, 운영 채택 전 별도 콘텐츠 검수 필요
- 기능 배포 후 사용 경로: 실험실의 핵심 키워드 / 문장. 저장 버튼과 오토파일럿 안내는 화면 및 `GUIDE.md`에 반영
