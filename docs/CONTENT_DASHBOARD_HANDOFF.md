## 1. 한 줄 정의와 차별점

**나만의 콘텐츠 매니징 에이전트.** 내가 만든 뉴스 위젯 안에서 소식이 요즘 소비에 맞춰 알아서 바뀌거나, 내가 직접 고정·편집하는 뉴스 홈.

- 차별점: 뉴스봇 같은 **단순 콘텐츠 모음이 아니다.** 콘텐츠뿐 아니라 **위젯(홈 구성)까지 사용자가 조정**한다.
- 즉 **메타로 구동되는 모듈형 구조**가 핵심 가치.

## 2. 핵심 은유와 구조 — 핸드폰 홈 위젯

핸드폰 홈 화면 위젯을 다루듯 뉴스 위젯을 얹고 옮기고 크기를 바꾼다.

```
뉴스 홈
   └─ 위젯 (핸드폰 홈 위젯 은유 · 팔로우/주제/분야/추천/인기 위젯)
        └─ 소식 (위젯 안 콘텐츠 카드)
             ├─ 알아서 채움 : 요즘 소비에 맞춰 자동 교체·정렬 (기본)
             └─ 고정        : 사용자가 핀으로 이 자리에 고정
```

- **위젯 크기 = 얼마나 볼지**: 작게 / 보통 / 크게. 크게 놓을수록 위에 크게 여러 개. (기존 "강도"를 홈 위젯 크기 은유로 대체)
- **새로운 소식 얼마나**: 익숙하게 ↔ 새롭게 손잡이 하나. 안 보던 소식을 얼마나 섞을지.
- 품질 통과분만 노출하되 화면에는 품질 등급을 표기하지 않는다.

## 2-A. 포털 홈 재정합 (실제 서비스 위에 얹기)

이 기능은 백지에서 홈을 만드는 게 아니라, **실제 포털 홈(Daum 참조) 위에 얹히는 레이어**다.

- **모듈 = 위젯**: 포털 홈의 콘텐츠 모듈(주요뉴스·이 시각 추천뉴스·실시간·우리지역 소식·라이브·쇼핑·분야 탭)이 곧 편집 가능한 위젯.
- **얹히는 레이어**: 홈을 갈아엎지 않고 그 위에 ① 상주 에이전트 버튼 ② 편집 모드(크기·순서·삭제·추가) ③ 왜?+피드백만 얹는다.
- **시스템 vs 위젯**: 검색·로그인·날씨 등 포털 기본은 편집 불가. 콘텐츠 모듈만 위젯으로 편집.
- **왜/피드백 전면화**: "이 시각 추천뉴스"의 ⓘ가 이미 있던 씨앗. 왜 떴는지 + 좋아요/관심없음을 그 자리에서.
- **손 + 말 둘 다**: 갤러리 시트로 고르거나 매니저에게 말하거나, 같은 위젯을 다룬다.
- 실제 모듈 → 위젯 매핑: 이 시각 추천뉴스→나를 위한 · 실시간→지금 인기 · 뉴스(주요·언론사·심층)→주제·성격 · 우리지역→지역 · 라이브·쇼핑→그대로.

## 3. 사용성 흐름

플로팅 에이전트 버튼이 진입점이자 상주 도우미 = 하나의 일관된 표면(첫 터치부터 상시 사용까지).

```
플로팅 버튼(진입) → 온보딩(에이전트 안내) → 대시보드(내 위젯들) → 홈 편집 ⇄ 적용
                                                    └ 같은 버튼이 상주(내 콘텐츠 매니저)
```

1. **진입** · "내 콘텐츠 매니저 시작" 플로팅 버튼. 복잡한 가입 미로 없이 여기서 시작.
2. **온보딩**(넷플릭스식) · 관심 분야 타일(최소 3) → 보는 방식(빠르게/깊게/가볍게) → **대화형(챗봇)** 으로 관심 인물·주제 찾기 → 완료 후 채워진 대시보드로.
3. **대시보드** · 내 위젯들. 위젯 안 소식은 알아서 채워지고, 왜 떴는지 쉬운 한 줄 + 피드백.
4. **홈 편집** · 위젯 추가 → 선택 → 설정 흐름 + 끌어서 옮기기·크기·지우기. 적용하면 대시보드 갱신.

## 4. 위젯 추가 흐름 (핸드폰 위젯과 동일 순서)

**① 위젯 추가(＋) → ② 위젯 선택(갤러리) → ③ 설정(크기·무엇을)**

- 위젯 갤러리(선택지): 나를 위한 추천 / 지금 많이 보는 / 팔로우 / 주제 / 분야 / 깊이 읽기.
- 설정: 위젯 크기(작게·보통·크게), 무엇을(인물·주제는 대화로 지정), 홈에 추가.

## 5. 킥 — "왜?"를 설명하고 피드백으로 배운다

- **왜 추천?** (위젯·추천마다) + **왜 이 소식?** (카드마다) 를 늘 붙인다. 블랙박스가 아닌 설명하는 추천.
- 그 자리에서 **맞아요 / 아니요 / 덜 보기** 피드백 → 다음 추천을 고친다. (고정도 강한 피드백)
- 설명 → 피드백 → 개선의 반복이 신뢰를 만든다.

## 6. 대화형(챗봇) = 내 콘텐츠 매니저

- 팔로우 인물·관심 주제·새 위젯 추가는 자유 문장으로. 매니저가 메타에서 후보를 찾아 "이렇게 만들까요?" 제안 후 추가.
- 온보딩의 관심사 찾기, 홈 편집의 위젯 추가에 쓰인다.

## 7. 용어 원칙 (공급자 말 → 사용자 말)

화면 문구는 전부 사용자 말. 아래 공급자 용어는 화면에서 쓰지 않는다.

| 공급자 말 | 사용자 말 |
| --- | --- |
| 강도 | 위젯 크기 (작게·보통·크게) |
| 전역 추천 강도 | 새로운 소식 얼마나 (익숙하게↔새롭게) |
| 재료 | 위젯 선택 (갤러리) / 위젯 종류 |
| 배치 | 위젯 옮기기 · 크기 바꾸기 |
| 생성 / 추가 | 위젯 추가 |
| 섹션 · 컴포넌트 | 위젯 · (위젯 안) 소식 |
| 자동/수동 토글 | 기본은 알아서 채움 + 고정(핀) |
| 글로벌 인기 | 지금 많이 보는 소식 |
| 메타 · 인텐트 · 페르소나 · 품질 G | (화면에서 노출 안 함) |

## 9. 결정된 것 / 열린 것

**결정됨**
- 위치: 실험실 > "콘텐츠 에이전트" 탭.
- 정체성: 나만의 콘텐츠 매니징 에이전트(진입점 + 상주 제어).
- 은유·구조: 핸드폰 홈 위젯 · 위젯 ⊃ 소식(알아서 채움 + 고정).
- 흐름: 플로팅 버튼 → 온보딩 → 대시보드 → 홈 편집. 위젯 추가 = 추가→선택→설정.
- 킥: 왜? 설명 + 피드백 루프.
- 관심사 찾기 = 대화형.
- 화면 문구는 사용자 말(공급자 용어 배제).
- PC(웹) + 모바일 앱 2버전.

**열린 것 (다음 논의)**
- 위젯 크기 단수: 작게·보통·크게 3단 vs 모양(정사각/가로/세로)까지.
- 홈 배열: 세로 한 줄 vs 웹 두 칸 격자. 자유도와 단순함 균형.
- "지금 많이 보는"의 범위: 전국 vs 나 같은 사람들. 얼마나 섞을지.
- "왜?" 설명의 솔직함 수위(프라이버시·설득력 균형).
- 위젯 종류 확장: 추천·인기·팔로우·주제·분야 외 랭킹·타임라인 등.
- 요즘 소비 신호 정의(무엇을 소비로 볼지)와 자동 재배치 규칙.
