## 사용 흐름

1. 평가 실행 후 **평가결과 → 상세 보기**에서 항목별 점수와 표본 확인
2. 관리자 권한으로 평가 모델 선택 후 **유료 진단 실행·재개** 실행
3. **건별 상세**에서 평가 당시 원문, 정답·산출의 주장과 근거 확인
4. 같은 정답·원문의 런 비교 또는 모델 비교에서 대응 차이와 신뢰구간 확인
5. 별도 사람 검수 후 프롬프트·모델의 운영 적용 여부 결정

- 진단 실행 시 평가 모델 및 임베딩 API 비용 발생
- 성공한 AI 판정의 재사용, 실패한 판정과 미측정 의미 평가만 재시도
- 요청 진행 중 중단 시 현재 호출 종료 후 다음 호출 경계에서 중단
- 표시 판정 비용의 임베딩 비용 제외, 단가 미상 호출의 일부 미집계 표시
- 기존 모델 비교·평가 실행 비용과 AI 진단 비용의 분리 표시

## 판정과 자동 적용

- 맥락 유사도: `solar-embedding-2-passage`의 코사인, 정확도 백분율로 해석 금지
- 항목 평균: 문서별 점수의 평균과 유효 문서 수, 결측 수 저장
- AI 원문 지지율: 문서 안 최소 주장 중 원문이 지지한다고 판정한 비율의 문서 평균
- AI 정답 정보 보존율: 원문이 지지하는 정답 주장 중 산출에 보존됐다고 판정한 비율의 문서 평균
- 원문이 지지하지 않는 정답 주장: 정보 보존 분모에서 제외하고 별도 기록
- 근거 검증: AI가 반환한 문장 ID의 실제 존재 확인, 서버에서 원문 문장 복원
- 저장된 메타 상태 정상률: `meta_status` 기반 진단, 원래 API 응답의 JSON 구문 검증률과 구분
- 대응 비교: 평가 버전·임베딩 모델·전체 표본·원문·정답 동일성 확인, 공통 일부 표본 수치만으로 전체 비교 가능 판정 금지
- bootstrap: 문서별 짝 차이의 2,000회 재표집, 고정 시드, percentile 95% 구간, 유효 쌍 1개 이하의 구간 미제시
- 종합 점수: 기존 가중 체계 유지, 새 평가가 있는 경우 공통 채점값 사용 및 리드문 의미 점수 참조
- AI 사실성·누락 점수: 종합 점수와 자동 적용 게이트에 미합산
- 회귀 방지: 기존 유해 미탐·서비스/사유·인텐트 값별 진단 유지, 새 메타 점수는 기존 최소 표본·하락 폭 기준에 연결
- 통과 불가: 메타 평가 대상 자료의 필수 항목 유효 정답 0건, 필요한 의미 점수 결측, 중복 표본, 전후 원문·정답 불일치
- 개선 후보 표시: 통계적으로 입증된 우위나 운영 적용 승인과 구분

## 과거 기록과 재현성

- 과거 평가 점수와 개발 실험 결과의 원본 보존
- 원문 스냅샷이 없는 과거 이력의 근거 진단 제한, 현재 콘텐츠로 임의 대체 금지
- 일반 평가의 스냅샷 지문 확인 후 원문 제공
- 모델 비교·오토파일럿에 평가 당시 원문·정답·산출 보존
- 진단 시작 시 원문·정답·산출·평가 모델 설정·프롬프트·버전 고정
- 평가 대상 또는 모델 조건이 달라진 진단의 덮어쓰기 재개 차단
- 원천키·입력·정책 버전을 포함한 DNM 정답 식별 규칙 사용
- 팀 소유 평가 확인 후 조회·실행·중단, 실행·중단 API의 관리자 권한 적용
- 기존 보고서 저장소 활용, DB 스키마 변경 없음
